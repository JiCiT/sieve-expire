# v0.1.0 public preview

Independent Sieve expire/expunge deadlines and guarded opportunistic account-wide
maintenance, native300 cooldown, persistent DMS installer, safe fallback and
software-only recovery. Exact DMS16.0.1 ARM64/u6 target only. No runtime builds or
startup downloads. Existing Sieve policies remain unchanged by installation.

Default installation enables enforcement of existing valid deadlines; expunge
is irreversible. Metadata-only mode is available. Original material CC0; upstream
licenses preserved. Contributions welcome, voluntarily.

Checksums are supplied without outer-archive signatures. Internal payload signatures
remain. Read compatibility, installation, qualification and known limitations before
installation. Bulk multi-save, enabled hibernation, other targets/backends and power
loss are unqualified. This preview is not an exact timer or latency SLA.
